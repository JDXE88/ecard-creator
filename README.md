# eCard Creator

[Visit the eCard Creator](https://jdxe88.github.io/ecard-creator)

## About
The **eCard Creator** is a collection of test eCard readers designed to help people send digital greeting cards to one another for free. Instead of spending money on traditional card services or wasting paper, this project aims to offer a simple, eco-friendly, and cost-effective way to share heartfelt messages with friends and family.

I am actively working on this now, so please bare with me, new to this.

## Features
- **Free to Use**: No hidden costs or subscriptions.
- **Eco-Friendly**: Saves paper and reduces environmental impact.
- **Easy to Share**: Send eCards digitally without the hassle of postage.
- **Multiple Designs**: Various eCard styles and themes in development.
- **Open for Improvement**: Ongoing enhancements to improve usability and functionality.

## How It Works
1. Visit [eCard Creator](https://jdxe88.github.io/ecard-creator).
2. Choose a test environment eCard design.
3. Customize your message.
4. Share the eCard link with your recipient.
